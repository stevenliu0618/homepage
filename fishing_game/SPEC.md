# 钓鱼RPG游戏规格文档

## 1. 项目概述

- **项目名称**: 悠钓物语 (Yuri Tsuri Monogatari)
- **类型**: 日式RPG钓鱼小游戏
- **核心功能**: 2D像素风格钓鱼玩法、商店系统、经验升级
- **目标用户**: 休闲游戏玩家

## 2. 视觉与渲染规格

### 场景设置
- **视角**: 2D俯视角/侧视角混合
- **分辨率**: 像素风格，320x180基础分辨率，放大显示
- **画布**: Canvas 2D渲染，每个像素块4x4显示

### 场景区域
- **村庄区域**: 左侧，草地，商店入口
- **水边区域**: 右侧，池塘边，钓鱼点
- **过渡**: 草地到水边的渐变

### 视觉风格
- **风格**: 16位像素艺术，日式RPG色调
- **配色**:
  - 草地: #4a7c59 (绿), #8fbc8f (浅绿)
  - 水面: #4a90a4 (蓝), #6bb3c9 (浅蓝)
  - 房屋: #8b7355 (木), #d4a574 (浅木)
  - 土地: #c9a66b (沙), #8b7355 (深土)

### UI元素
- **字体**: 像素风格渲染
- **HUD**: 顶部显示金币、经验值、背包
- **商店界面**: 居中弹窗，列表选择
- **钓鱼小游戏**: 圆形力度条 + 时机指示器

## 3. 游戏系统

### 角色属性
- **金币 (Gold)**: 用于购买道具，初始100
- **经验值 (EXP)**: 钓鱼成功获得，升级增加属性
- **等级 (Level)**: 1-99，钓鱼经验累积升级
- **攻击力 (ATK)**: 影响钓鱼小游戏伤害

### 背包系统

- 物品类型: 鱼、饵、竿、杂货

## 4. 钓鱼玩法

### 钓鱼阶段
1. **就位**: 角色移动到水边，显示钓鱼姿势
2. **等待**: 随机3-15秒，出现"..."动画
3. **咬钩**: 屏幕闪烁，显示"！上钩了！"提示
4. **反应窗口**: 1.5秒内按空格键进入小游戏
5. **小游戏**: 成功则获得鱼，失败则鱼逃跑

### 钓鱼小游戏
- **圆形力度条**: 中心向外扩展的圆环
- **目标区域**: 随机的绿色区域
- **按键**: 空格键停止力度条
- **判定**:
  - 落在绿色区域: 成功
  - 落在红色区域: 失败
  - 精准度影响获得的鱼品质

## 5. 交互规格

### 键盘控制
| 按键 | 功能 |
|------|------|
| 方向键/WASD | 移动角色 |
| 空格 | 钓鱼/确认 |
| E | 交互/进入商店 |
| I | 背包 |
| ESC | 关闭菜单 |

### 交互对象
- **商店NPC**: 站在商店门口，显示"E交互"
- **水边**: 走到水边显示钓鱼提示
- **公告牌**: 显示游戏帮助

## 6. 音频 (可选)
- 背景音乐: 轻快的8-bit风格
- 音效: 钓鱼、获得物品、升级
